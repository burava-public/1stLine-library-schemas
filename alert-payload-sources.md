# Alert Payload Source Inventory

Research date: 2026-05-14

This document tracks candidate sources for building a library of alert producer payloads and receiver payload schemas. Sources are ranked by practical value for extracting common key pairs, example payloads, and validation rules.

## Provenance Tags

- `official`: Vendor or project documentation/source of truth.
- `upstream-test`: Test code from the producer or receiver project.
- `repo-fixture`: Example payload files from an open-source project.
- `adapter-derived`: Payload shape inferred from an integration adapter or normalizer.
- `template-derived`: Template or variable catalog rather than emitted raw payload.
- `community-synthetic`: Community example with unclear provenance.
- `needs-capture`: Public docs confirm the integration exists, but the emitted request body needs live capture or vendor confirmation.

## Initial Import Recommendation

Start with these source groups:

1. Alertmanager and Grafana upstream notifier tests for producer-to-receiver pair behavior.
2. Zabbix `templates/media/*` release-pinned YAML/scripts for Zabbix-to-receiver examples.
3. Pingdom official webhook examples for uptime-monitoring fixed-schema examples.
4. Grafana webhook docs, Azure common schema, AWS CloudWatch SNS/EventBridge, Google Cloud Monitoring, Cloudflare Notifications, Graylog, and Dynatrace for structured producer schemas.
5. Slack, Discord, Teams, Telegram, Mattermost, Rocket.Chat, Opsgenie, PagerDuty, ServiceNow, Jira, Zendesk, GitHub, Google Chat, Matrix, Webex, and Linear for receiver payload validation.
6. `moan0s/alertbot`, `arabold/aws-to-slack`, `slok/alertgram`, and `mr-karan/alertmatter` as practical raw fixture supplements.

## Known Gaps To Continue Researching

- Live-capture or vendor-confirmation payloads for StatusCake, Better Stack Uptime outgoing webhooks, UptimeRobot, HetrixTools, and Cronitor.
- Better raw emitted payloads for Datadog, New Relic, Sentry, PagerDuty V3 webhooks, ServiceNow Event Management, Elastic/Kibana, OpenSearch Alerting, Logz.io, Mezmo, and Site24x7.
- Release-pinned extraction from Zabbix `templates/media/*` and Grafana/Alertmanager upstream tests.
- Version fixtures for Graylog, Teams workflow/webhook variants, Dynatrace classic notifications versus workflows, and Cloudflare alert-type `data` variants.
- Recommended canonical templates for custom/template-driven providers: Checkly, Healthchecks.io, Honeycomb, Site24x7, Logz.io, Mezmo, OpenSearch, Kibana, and Sematext.
